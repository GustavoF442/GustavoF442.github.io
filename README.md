# gustavof442.github.io

Portfólio pessoal de Gustavo Henrique Fraga. HTML, CSS e JS puros, sem build.

## Publicar no GitHub Pages

1. Crie um repositório chamado `GustavoF442.github.io`.
2. Envie `index.html`, `style.css`, `script.js`, `.nojekyll` e a pasta `assets/` para a branch `main`.
3. Em **Settings → Pages**, escolha *Deploy from a branch* → `main` / `root`.
4. O site fica em `https://gustavof442.github.io`.

## Editar

- Certificações: em `#roadmap`, troque o `data-status` de cada etapa para `todo`, `doing` ou `done`. A barra de progresso e o contador se atualizam sozinhos.
- Projetos para clientes: seção `#clientes`. Cada card tem `data-status="online"` (no ar) ou `"ready"` (pronto, em publicação). Prints ficam em `assets/shots/`.
- Foto: `assets/gustavo.png`. Logos das empresas: `assets/logos/`.
- Cores e fontes: variáveis no topo de `style.css`.
